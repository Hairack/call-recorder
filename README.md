# Диктофон разговоров (iPhone)

Приложение для iPhone, которое записывает разговоры через микрофон.
Интерфейс полностью на русском языке.

## Что важно знать (честно)

iOS **не даёт** ни одному стороннему приложению доступ к звуку самого
телефонного звонка. Это ограничение Apple. Поэтому приложение записывает
разговор так: вы включаете **громкую связь**, и микрофон слышит оба голоса.

Встроенная запись звонков в iOS 18 работает только на iPhone 15 Pro и новее
и в России недоступна. На iPhone XR её нет и быть не может.

## Что умеет приложение

- Запись через микрофон (кнопка «Начать запись»).
- Автозапись: старт при громкой речи (значок молнии).
- Список записей, поиск, переименование, удаление.
- Плеер: пауза, перемотка ±15 секунд, отправка файла (мессенджер/почта/диск).
- Поле текстовой расшифровки рядом с записью.
- Файлы формата m4a, доступны в приложении «Файлы».

## Структура

- `Sources/` — исходный код (SwiftUI).
- `project.yml` — конфигурация проекта (XcodeGen).
- `.github/workflows/build-ipa.yml` — сборка `.ipa` в облаке (macOS).
